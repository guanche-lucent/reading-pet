# 读书养宠：你读的每一页都在喂养一只知识宠物

## 产品点子

上传一本 PDF/EPUB，系统拆成每天 5 分钟的小任务。读完、回答一个问题或复述一个观点，就能喂养宠物；宠物的性格和房间逐渐受到书中内容影响。

## 能力组合来源

- G07 `virgiliojr94/book-to-skill`：把 PDF、EPUB、DOCX 等拆成章节、概念、规则和术语。
- G18 `run-llama/liteparse`：本地快速解析 PDF，输出带标题、表格和图片的 Markdown。
- G04 `ayghri/i-have-adhd`：把内容压缩为一个明确行动、少量步骤和可见进度。
- G19 `helloianneo/ian-xiaohei-illustrations`：生成固定“小黑角色”风格的知识场景和宠物反馈图。
- G08 `rohitg00/agentmemory`：记住用户读过什么、卡在哪里、哪些概念经常忘记。
- Product Hunt：Yomi 的创意点是“孩子朗读就能喂猫”，不是用连续打卡、排行榜制造压力。

## 低难度 MVP 边界

- 只支持文本型 PDF，不支持 EPUB、DOCX、扫描件 OCR。
- 每天一张任务卡。
- 一只静态宠物。
- 一道复述题。
- 不用连续打卡、排行榜制造压力。
- 评分：新 5/5｜好玩 5/5｜实用 5/5｜难度 2/5。
