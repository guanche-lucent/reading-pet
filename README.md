## 配置隔离：为什么每个项目一份 .env

跑脚本时会先加载**本项目的 `.env`**，而且**环境变量优先于引擎自带的 `.env`**。所以：

- 读书养宠用哪把钥匙、哪个模型，只看这个文件夹里的 `.env`
- 以后新项目（比如呼噜天气）用自己的 `.env`，**用另一把钥匙也不会互相影响**
- 引擎自带的 `.env` 只是"项目没配时的兜底"

| 变量 | 作用 | 本项目当前值 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 模型服务钥匙 | 蚂蚁数科 MaaS 的 key（已配） |
| `ANTHROPIC_BASE_URL` | 网关地址 | `https://maas-api.antdigital.com` |
| `MODEL_ID` | 用哪个模型 | `deepseek-flash` |
| `ANTHROPIC_TIMEOUT` | 单次调用超时（秒） | `600`（慢推理模型必须放宽，引擎默认 120） |

⚠️ `.env` 含密钥：**别提交 git、别截图、别外发**。要分享配置就发 `.env.example`。

## 新项目怎么开（同一个习惯）

```sh
cd /Users/chen/Documents/projects
cp -R _项目模板 项目名        # 模板已备好：docs/、产物/、src/、.env.example、两个脚本
cd 项目名
cp .env.example .env          # 填这个项目自己的钥匙
./检查配置.sh
```
