# 引擎改动补丁

这里存的是**我在引擎（agent-blueprint，Hubo 的开源项目）里做的唯一一处改动**，用补丁文件保存，
而不是把整个引擎复制一份到 GitHub（那是别人的项目，没必要做镜像）。

| 文件 | 改了什么 | 对应引擎提交 |
|---|---|---|
| `0001-引擎改动-单次调用超时可配置.patch` | 增加 `ANTHROPIC_TIMEOUT` 环境变量：单次模型调用超时默认仍是 120 秒，可放宽（本机设为 600 秒，因为蚂蚁数科 MaaS 上的推理模型单次常超过 2 分钟）；另补两分支测试与 `.env.example` 说明 | `ec376e8` |

## 怎么用（在一份干净的引擎副本上）

```sh
cd /你的路径/agent-blueprint
git checkout -b 我的超时改动          # 建议新开分支
git am /你的路径/读书养宠/patches/0001-引擎改动-单次调用超时可配置.patch
```

打完之后，在引擎的 `.env` 里加一行即可生效：

```sh
ANTHROPIC_TIMEOUT=600
```

不打补丁也能用引擎——只是遇到慢模型时会以 120 秒为限，超过就报 `APITimeoutError`。
