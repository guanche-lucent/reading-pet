# 读书养宠 · 可点击原型

**打开方式**：双击 `index.html`（或在浏览器里打开这个文件）。单文件、离线可用、不需要安装任何东西。

```sh
open /Users/chen/Documents/projects/读书养宠/prototype/index.html
```

## 这是什么

用来验证**产品节奏**，不是验证技术。核心问题只有一个：

> 每天一张 5 分钟卡 + 复述一次就喂宠物，人愿意坚持吗？宠物反馈看得懂吗？

## 哪些是真的、哪些是假的（别搞混）

| 部分 | 状态 |
|---|---|
| 页面流程、宠物状态变化、复习卡、删除入口 | ✅ 真做出来了，可以点 |
| 复述判定 | ⚠️ **假的**：本地关键词匹配模拟，不是模型判定（真产品走 `judge_retelling` 工具） |
| 宠物与房间图形 | ⚠️ **占位**：内联 SVG 画的，不是最终插画（正式版是 4 状态 × 3 房间 = 12 张静态图） |
| 样章文字 | ✅ 自写的示例文本（避免版权问题），不是真书 |
| 数据 | 存在浏览器 localStorage，清一下缓存就没了 |

## 原型里已经体现的 6 项决策

| 决策 | 在原型里怎么体验 |
|---|---|
| **1A** 停读 7 天 → 复习卡 | 点「模拟停读 7 天回来」：节选消失、顶部出现说明，**卡片和进度还在** |
| **3A+** 原文不留存 | 「设置」页写着"原书文件：已清理（不留存）" |
| **4A** 异步出卡 | 「开始读」有 5 分钟计时与进度条 |
| **5A** 4 状态 × 3 房间 | 点「切换房间主题 / 切换宠物状态」，共 12 种组合 |
| **6A / 判定从宽** | 故意写一句很短的话提交，会看到「存疑（不算失败）」 |
| **无压力** | 通篇没有打卡、没有排行榜、没有"连续 N 天"；不做也只提示"今天先到这里" |

## 拿去给人试的 5 分钟脚本

**别解释产品**，把手机（或这个页面）递过去，只说一句：
> "你上传了一本书，它每天给你一张 5 分钟的卡。你试试。"

然后观察这 4 件事：

1. 他能不能**不解释就点完一轮**（读 → 复述 → 拿反馈）？
2. 提交后，他**看没看懂宠物为什么变**？
3. 他会不会**主动点去宠物页**看一眼？
4. 做完一张，他**有没有想看下一张**（或者问"明天还能来吗"）？

最后问 3 个问题（原话记录，别引导）：

- 刚才那个宠物变化，你觉得是怎么来的？
- 明天你还会来吗？为什么？
- 如果让你自己上传一本书，你最担心什么？

**判断线**：5 个人里至少 4 个能独立完成一轮，且至少 3 个能说清"宠物是因为我复述了才变的"——说明节奏成立。如果多数人做完一轮就不想再开，**先改节奏，别去写代码**。

## 已知不足（我故意没做）

- 不能真的上传 PDF（真实上传要等代码骨架）
- 只有一张示例卡，没有"第二天换新内容"的连续性
- 没有失败重试次数、超时、模型不可用等异常演示
- 宠物变化是简化规则（每完成 3 张换房间），真产品按「内容标签 + 完成情况」映射
